🔗 連線 N8N Cloud + Google Sheets
在 N8N Cloud 匯入 Workflow 並啟用後，複製 Production Webhook URL（格式：https://xxx.app.n8n.cloud/webhook/portfolio）貼入下方。
未設定則使用本機 localStorage 離線模式，資料不會跨裝置同步。
Step 1
在 Google Sheets 建立試算表，新增兩個工作表：assets 和 liabilities
Step 2
在 N8N Cloud 匯入 portfolio-n8n-cloud-workflow.json，填入試算表 ID 和 Google 憑證
Step 3
點 Workflow 右上角 Activate，複製 Production Webhook URL
Step 4
將 URL 貼入上方輸入框，點「儲存並連線」。手機和電腦使用同一個 HTML 即可同步
