# 作廢紀錄機制 — n8n 建置規格

> 背景：`dashboard.html` 總表重複列的「🗑 作廢」按鈕改為**業務自行決定、免審核、立即生效**，
> 但要留下紀錄。前端已改完（見 `dashboard.html` `submitVoidRequest()`），呼叫
> `/webhook/void-report-self`。**這三個東西完全不存在，要全新建立**——原本 `submit-void`／
> `get-void-requests`／`execute-void` 這三個 webhook 從來沒建過，`edit-request.html`／
> `review.html` 裡呼叫它們的程式碼一直是壞的，這次順便把「有紀錄可查」這件事做起來。
>
> 移除方式採**標記＋過濾**（不是真的刪除那一列）：`報刀單格式` 加一欄「已作廢」，
> 讀取資料的 webhook 過濾掉已作廢的列。資料還在，不怕刪錯列、事後也查得到。

## 一、Google Sheets 要先做的事

### 1. `報刀單格式`（gid=713793623）加一欄
在最後面加一欄 **`已作廢`**，所有既有資料留空即可。

### 2. 新增分頁 `作廢紀錄表`
表頭（第一列）：

```
流水號  日期  醫院  醫師  病人  病歷號  品項數量  申請者  申請時間  狀態  執行者  執行時間
```

建好後把 **gid** 告訴我／記下來，n8n 的 Google Sheets node 要選這個分頁。

> 欄位對應 `review.html` 既有的作廢卡片渲染邏輯（`r['流水號']`、`r['狀態']`、`r['日期']`、
> `r['醫院']`、`r['醫師']`、`r['病人']`、`r['病歷號']`、`r['申請者']`、`r['申請時間']`、
> `r['執行者']`、`r['執行時間']`）——照這個表頭建，`review.html` 完全不用改，
> 直接就能看到紀錄（因為每筆一寫入就已經是「已執行」狀態，不會停在待審）。

## 二、n8n 新建 Webhook A — `/webhook/void-report-self`

**這是核心動作**：業務按下作廢，這支同時完成「登記」跟「執行」。

### Request（dashboard.html 已經在送這個）
```json
{
  "token": "...",
  "流水號": "IV26050801",
  "日期": "2026/08/17",
  "醫院": "署北",
  "醫師": "陳建龍",
  "病人": "王小明",
  "病歷號": "A001",
  "品項數量": 2,
  "申請者": "Ivan",
  "role": "admin"
}
```

### Node 流程
1. **Webhook**（POST，path=`void-report-self`）
2. **Code node**「處理作廢資料」：
   ```js
   const body = $input.first().json.body || {};
   const { 流水號, 日期, 醫院, 醫師, 病人, 病歷號, 品項數量, 申請者 } = body;

   if (!流水號 || !申請者) {
     return [{ json: { success: false, message: '流水號和申請者必填' } }];
   }

   const now = new Date();
   const pad = n => String(n).padStart(2, '0');
   const timestamp = `${now.getFullYear()}/${pad(now.getMonth()+1)}/${pad(now.getDate())} ${pad(now.getHours())}:${pad(now.getMinutes())}`;

   return [{ json: {
     流水號, 日期: 日期 || '', 醫院: 醫院 || '', 醫師: 醫師 || '',
     病人: 病人 || '', 病歷號: 病歷號 || '', 品項數量: 品項數量 || 0,
     申請者, 申請時間: timestamp,
     狀態: '已執行', 執行者: 申請者, 執行時間: timestamp
   } }];
   ```
3. **Google Sheets（Append）**「寫入作廢紀錄」：目標分頁 `作廢紀錄表`，`columns.value` 對應上面 Code node 輸出的每個欄位（比照現有 `寫入申請表1` node 的寫法）。
4. **Google Sheets（Get Row(s)）**「讀取報刀單格式」：目標分頁 `報刀單格式`，用來抓出符合 `流水號` 的那一列的 `row_number`（比照現有 `讀取申請（審核用）1` node 的寫法）。
5. **Code node**「找出目標列」：
   ```js
   const 流水號 = $('處理作廢資料').first().json.流水號;
   const allRows = $input.all().map(item => item.json);
   const target = allRows.find(r => String(r['流水號']) === String(流水號));
   if (!target) return [{ json: { success: false, message: '找不到報刀單' } }];
   return [{ json: { row_number: target['row_number'], 已作廢: '是' } }];
   ```
6. **Google Sheets（Update）**「標記已作廢」：目標分頁 `報刀單格式`，`matchingColumns: ['row_number']`，只更新 `已作廢` 欄位為 `是`（比照現有 `更新申請表狀態1` node 的寫法）。
7. **Respond to Webhook**：`{ "success": true }`

> 步驟 4-6 如果找不到對應列（`target` 是 undefined），要能正確回傳失敗訊息，不要整條卡死——這點跟你之前遇過的「Get Row(s) 查到 0 筆整條停止」是同一個坑，記得該 Get Row(s) node 也要開 **Always Output Data**。

## 三、n8n 新建 Webhook B — `/webhook/get-void-requests`

給 `review.html` 撈作廢紀錄用（`review.html` 前端程式碼已經在呼叫這支，只是後端從沒建過）。

### Request
```json
{ "token": "...", "role": "admin", "username": "Ivan" }
```

### Node 流程
1. **Webhook**（POST，path=`get-void-requests`）
2. **Google Sheets（Get Row(s)）**：讀取 `作廢紀錄表` 全部
3. **Code node**「整理清單」：
   ```js
   const allRows = $input.all().map(item => item.json).filter(r => r['流水號']);
   allRows.sort((a, b) => new Date(b['申請時間'] || 0) - new Date(a['申請時間'] || 0));
   return [{ json: { success: true, total: allRows.length, data: allRows } }];
   ```
4. **Respond to Webhook**：`{{ $json }}`

同樣記得 Get Row(s) node 開 **Always Output Data**（分頁剛建好是空的時候會用到）。

## 四、修改既有 Webhook — `get-cases` 加過濾

找到 `get-cases` workflow 裡讀取 `報刀單格式` 之後、回傳資料之前的那個 Code node，加一行過濾：

```js
// 在既有的整理/篩選邏輯裡，加這一行：
allRows = allRows.filter(r => r['已作廢'] !== '是');
```

**這是現有正式在用的 webhook，改的時候小心**：只加過濾條件，不要動到其他既有邏輯。改完記得測一下總表還能正常撈到資料。

## 五、修改既有 Webhook — `get-performance` 也要加同樣的過濾

**容易漏掉的地方**：`performance.html`（業績儀表板）呼叫的是**另一個獨立的 webhook** `get-performance`，不是 `get-cases`。如果只改 `get-cases`，作廢的案件會從總表消失，但業績儀表板還是會繼續把它算進業績——這樣業務作廢重複案件後，業績數字反而沒有跟著少掉重複計算的部分，等於白作廢。

一樣的過濾邏輯（`已作廢 !== '是'`）也要加進 `get-performance` 讀取 `報刀單格式` 之後的整理步驟。

## 六、完成後怎麼測試

1. 去總表隨便找一組被標記「重複」的資料，用其中一筆的業務身份登入。
2. 點「🗑 作廢」，確認畫面跳出成功訊息、該筆立刻從總表消失。
3. 去 Google Sheets 檢查：`報刀單格式` 那一列的「已作廢」欄位是不是變成「是」；`作廢紀錄表` 有沒有新增一筆、狀態是「已執行」。
4. 去 `review.html` 的「作廢申請」分頁，確認剛剛那筆有出現、顯示已執行。
5. 去 `performance.html` 確認該業務的業績數字有沒有正確扣掉（跟作廢前比對）。
